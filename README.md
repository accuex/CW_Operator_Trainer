## 音で覚えて、耳で追う

短点と長点のリズムを聴いて、ひとつずつ符号を覚える。少ない文字から始めるコッホ法で、聴き取れる範囲を広げる。慣れてきたら、単語やコールサイン、数文字を頭に残してから書く遅れ受信へ。

文字の速さと文字間の間隔を別々に調整できるので、速い音に耳を慣らしながら、答える時間はゆっくり取れます。取り違えた文字や反応時間は「苦手分析」で振り返れます。

覚えた符号はカード図鑑に。練習の積み重ねが、レベルやカードとして残ります。

## ダイヤルを回して、CQを探す

舞台は7MHz帯の仮想バンド。ウォーターフォールを眺め、ダイヤルを回し、混信やノイズの中から相手の信号を拾います。呼びかけ、レポートを交換して、73で交信を終える。その流れをブラウザで体験できます。

最初はチュートリアルから。慣れたら、自分の楽しみ方に合わせてモードを選べます。

| モード  | 楽しみ方                                               |
| ------- | ------------------------------------------------------ |
| QSO     | CQを出している局を探し、ひとつの交信をじっくり進める。 |
| CQ Run  | 自分からCQを出して、呼んできた局と次々に交信する。     |
| Pileup  | 重なって聞こえるコールサインから、ひと局ずつ拾う。     |
| Contest | レポートとナンバーを交換し、テンポよくログを埋める。   |
| 和文QSO | 和文のやりとりを聴き、額表に書き取る。                 |

受信を助けるDECODE表示も使えます。

## 一総通を目指す

一総通の教材メニューから、電気通信術・地理・専門英語を選べます。前回の教材は「続きへ」から、また開けます。

### 電気通信術

和文普通語・欧文暗語・欧文普通語を、試験呼称から終了符号まで通して練習できます。科目ごとに1,000セットを収録。手書きで取りたい日は視聴モード、採点して振り返りたい日は入力モードを選べます。

額表を使った受信や、通と通の間の休止も含めて、試験の流れに慣れていきます。

### 地理

過去問に登場した地名を、地図で覚える教材です。日本、北海・バルト海をはじめとする8エリアから、覚える範囲を選んで学習できます。

白地図の練習は「点を見て名称を答える」「名称から位置を選ぶ」の2通り。10問・20問・全問から選べて、間違えた地点はもう一度。途中で終えた練習の再開や、最近間違えた地点の復習にも対応しています。

地図をゆっくり眺めたいときは、**マップモード**へ。海岸局、港・都市、地形、海峡・水道などのレイヤーを重ね、地名を隠したり、集計期間を変えたりできます。よく登場する地点ほど大きなマーカーで表示され、位置関係と頻度を一緒に見渡せます。

頻度は **「選択肢登場回数（正解・不正解を問わず）」**。地点を選ぶと、登場した試験期や出典も確認できます。位置を確認できた地点・範囲地物を地図に載せ、OCR参考集計は確認済みの集計と区別して表示しています。

### 専門英語

知っている単語なのに、文脈が変わると意味が取れない。たとえば *guard* は周波数を「聴守する」、*pilot* は海事では「水先人」。一総通の過去問に出る無線・海事・航空の英語を、場面ごとに読み解きます。

「誰が通信するか」「遭難・救助」「港・操船」など8つの場面から、最小32・標準74・しっかり101項目の範囲を選べます。一般的な意味と専門的な意味を並べ、短い例文や関連表現をつなげて学びます。

規定の英文は、主体・義務・禁止・許可・条件・例外に分けて読む。訳語を覚えるだけでなく、「誰が、何を、どんな条件で行うのか」を捉える教材です。読んだ項目を確認済みにしておけば、次は前回の範囲・場面・項目から開けます。

## 記録を残して、また続きから

学習記録は、使っているブラウザに保存されます。ログインすると、本体の進捗や回答履歴を別の端末でも使えます。設定画面からJSONのバックアップを書き出すこともできます。

地理の学習履歴は端末内の保存です。地理画面から専用のJSONを書き出し・読み込みできます。本体のクラウド同期やバックアップとは別に扱います。

専門英語の確認済み記録と閲覧位置も、このブラウザに保存されます。専門英語の端末間同期・バックアップにはまだ対応していません。

ブラウザのサイトデータを消す前に、残したい記録をバックアップしておいてください。ホーム画面に追加して、アプリのように使うこともできます。

## ローカルで動かす

Node.js **22.13.0以上**とnpmを用意してください。

```bash
git clone https://github.com/accuex/CW_Operator_Trainer.git
cd CW_Operator_Trainer
npm ci
npm run dev
```

表示されたURLをブラウザで開きます。音はPLAYやSTARTなどの操作で鳴り始めます。

| コマンド                     | 用途                           |
| ---------------------------- | ------------------------------ |
| `npm run dev`                | 開発サーバー                   |
| `npm run build`              | 本番ビルド                     |
| `npm run start`              | ビルド済みアプリの起動         |
| `npm test`                   | テスト                         |
| `npm run lint`               | コードチェック                 |
| `npm run generate:exam-sets` | 電気通信術の問題セットを再生成 |

<details>
<summary>開発構成・設定</summary>

React 19 / TypeScript、Next.js 16互換のVinext / Vite構成です。音声はWeb Audio APIで生成し、ブラウザ内の記録にはIndexedDBとlocalStorageを使っています。PWAにも対応しています。

```text
app/                 画面、リグUI、額表コンポーネント
lib/                 CW音響、交信、採点、分析、保存、地理・専門英語学習
public/geography/    地理教材の構造化データと地図データ
public/english/      専門英語の教材マスター
public/cards/        カードイラスト
public/fonts/        フォント
data/exam/           電気通信術の問題セットと辞書
scripts/             データ生成・QA
docs/                設計・検証資料
```

任意の設定は [`.env.example`](./.env.example) を参照してください。クラウド同期のAPI接続先は `NEXT_PUBLIC_API_BASE_URL`、Google Analyticsは `NEXT_PUBLIC_GA_MEASUREMENT_ID` で指定できます。AnalyticsはIDを設定した本番ビルドで読み込まれます。`NEXT_PUBLIC_*` の変更後は再ビルドが必要です。

電気通信術の問題生成は [`scripts/generateExamSets.mjs`](./scripts/generateExamSets.mjs)、辞書は [`data/exam/dicts.json`](./data/exam/dicts.json)。カード画像の対応表は [`lib/cardArtwork.ts`](./lib/cardArtwork.ts) にあります。

</details>
